# weak-zip

**Category:** Forensics
**Difficulty:** Easy

We recovered a password-protected zip from a suspect's desktop, along with
a list of passwords found in their browser's saved-password export. One
of them opens the archive.

## Files

- `secret.zip` — the password-protected archive
- `wordlist.txt` — candidate passwords recovered separately

## Hint

You don't need to guess — automate trying every candidate password
against the archive.
